# Power_BI---AI-Job-Market-Intelligence-Dashboard
Built with Power BI, this interactive dashboard offers a comprehensive view of the global AI job landscape, enabling users to explore patterns in hiring, salary trends, remote work, and in-demand skills.

🔍 Key Insights:
 ✅ Executive-level roles offer the highest salaries (up to $188K)
 ✅ Remote, Hybrid & Onsite roles are evenly distributed (~33% each)
 ✅ Python, SQL, TensorFlow & Kubernetes lead skill demand
 ✅ Full-Time, Contract, Freelance & Part-Time jobs are well-balanced
 ✅ Job postings show a gradual decline — market stabilizing

📊 Dashboard Highlights:
▪️ Market Overview: Top companies, salary by experience, employment types
▪️ Remote Insights: Distribution of job types & salaries by work model
▪️ Timeline & Skills: Job trends over time and top skills (Word Cloud)

🛠️ Tools Used: Power BI | DAX | Data Modeling | UX Design
